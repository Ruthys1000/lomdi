# LearnIt — מחולל לומדות HTML מבוסס בלוקים

כלי ויזואלי לבניית לומדות בעברית: המשתמש בונה לומדה מפרקים ובלוקים, עורך אותה
ישירות על הקנבס, שומר את הפרויקט וממנו מייצא **לומדת HTML עצמאית** — כזו שרצה
מפתיחת `index.html` בלי שרת, בלי CDN ובלי תלות במחולל, וניתנת להעלאה ל-Moodle
כתיקיית תוכן או כ-ZIP.

> סטטוס: אב-טיפוס (POC) בפיתוח. שלב 1 (שלד הפרויקט) הושלם.

## התקנה והרצה

דרישות: Node.js 20 ומעלה.

```bash
npm install
npm run dev
```

הכתובת תודפס לטרמינל (ברירת מחדל: <http://localhost:5173>).

| פקודה | מה היא עושה |

## הארכיטקטורה בקצרה

מקוד מקור אחד נבנות **שתי** חבילות:

| חבילה | Entry | תוצר | מה בפנים |
| --- | --- | --- | --- |
| **עורך** | `src/main.tsx` | `dist/` | האולפן: סרגלים, פאנלים, גרירה, TipTap, שמירה, ייצוא |
| **runtime של הלומדה** | `src/runtime/main.tsx` | `public/runtime/app.js` + `styles.css` | React + `CourseRenderer` + ה-Renderers של הבלוקים בלבד |

שתיהן מייבאות את אותם רכיבי `Renderer`. לכן התצוגה המקדימה בעורך והלומדה
המיוצאת אינן שתי מימושים שצריך לסנכרן — הן אותה יחידת קוד. בזמן ייצוא, העורך
אורז את `public/runtime/` לתוך ה-ZIP.

מכאן נגזרות שלוש מוסכמות שהפרתן שוברת את התוצר:

1. **קוד עורך לא נכנס לאזור ה-Renderer.** `src/renderer/**`, `src/runtime/**`
   ו-`src/blocks/*/Renderer.tsx` אינם מייבאים מ-`editor/`, מה-stores, מ-TipTap
   או מ-dnd-kit. הכלל נאכף ב-`eslint.config.js` — הפרה מפילה את ה-lint.
2. **רגיסטרי אחד לכל צד.** `registry.runtime.ts` מחזיק Renderers בלבד;
   `registry.editor.ts` (שלב 3) מחזיק את ההגדרה המלאה. רגיסטרי מאוחד היה גורר
   את כל העורך לחבילת הלומדה.
3. **בלוקים שומרים `assetId`, לעולם לא כתובת.** ההמרה לכתובת נעשית דרך
   `resolveAssetUrl` ב-`RenderContext`: `blob:` בעורך, נתיב יחסי בייצוא. כך
   מובטח מבנית שנתיבי `blob:` לא יכולים לדלוף לתוצר.

`public/runtime/` הוא תוצר build ולכן אינו נשמר בגיט. `npm run dev` ו-`npm run build`
בונים אותו קודם, כדי שהייצוא לא ישלח רנדרר מיושן.

## מבנה התיקיות

```
src/
  model/       מודל התוכן: טיפוסים, סכמות, פעולות טהורות. ללא תלות ב-React
  blocks/      תיקייה לכל סוג בלוק: Renderer / Editor / Settings / הגדרה
  renderer/    מה שהלומד רואה — משותף לתצוגה מקדימה ולתוצר
  runtime/     נקודת הכניסה של הלומדה המיוצאת
  editor/      האולפן: סרגלים, קנבס, פאנלים, ספריות
  state/       zustand: מסמך הלומדה (נשמר) מול מצב העורך (לא נשמר)
  persistence/ IndexedDB, שמירה אוטומטית, קובץ פרויקט
  export/      בניית ה-ZIP וה-index.html
```
